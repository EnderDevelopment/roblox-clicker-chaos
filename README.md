# Clicker Chaos

This project is a simple clicker game for Roblox, designed to be easy to set up and play. It includes server-side logic to track player scores and a client-side UI to display the score and handle click events.

## Install

1. Download the project files from the GitHub repository.
2. Open Roblox Studio.
3. Place the `ClickerGameScript.server.lua` script in the `ServerScriptService` folder.
4. Place the `ClickerGameUI.client.lua` script in the `StarterPlayerScripts` folder.

## Use

1. Start the game in Roblox Studio.
2. Click the "Click Me!" button to increase your score.
3. Your score will be displayed on the screen.
